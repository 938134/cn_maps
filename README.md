# 国内地图 { #ha-cnmaps }

把 Home Assistant 内置地图（地图面板、地图卡片、实体详情小地图）的底图换成高德、腾讯、天地图等国内地图源，也可切回 HA 自带的默认底图。

瓦片抓取、坐标纠偏（GCJ-02 → WGS84）全部在 HA 服务端完成，手机 App、网页、老设备看到的地图完全一致，密钥不会下发到浏览器。

## 功能特性

- **6 种底图**：HA 自带地图、高德路网、高德卫星、腾讯卫星、天地图矢量、天地图影像
- **可切回 HA 自带底图**：HA 2026.10 起已更新内置地图，不代理瓦片、不写自定义样式，原生体验
- **服务端纠偏**：自动把 GCJ-02 坐标系偏移修正回 WGS84，路网与实体精准对齐
- **像素级精确纠偏**：每张瓦片最多拼 4 张源图，精度到亚像素；关闭后省 CPU
- **地图工具栏**：地图右下角浮动按钮，一键切换底图数据源，无需进设置页
- **菜单自适应**：切换菜单自动根据屏幕剩余空间上下翻转、水平夹取、限高可滚动，手机竖屏/弹窗内不溢出
- **暗色模式压暗**：栅格底图无暗色版本，可在 HA 暗色主题下自动压暗
- **零前端依赖**：不装 Lovelace 卡片、不拦截瓦片请求，只换一个 MapLibre 样式

## 安装

### 通过 HACS 安装（推荐）

1. 打开 HACS → 集成 → 右上角菜单 → 自定义存储库
2. 添加本仓库地址，类别选「集成」
3. 搜索「国内地图」并安装
4. 重启 Home Assistant

### 手动安装

1. 下载 `custom_components/ha_cnmaps/` 整个目录
2. 放到 HA 配置目录的 `custom_components/ha_cnmaps/`
3. 重启 Home Assistant

## 配置

1. 设置 → 设备与服务 → 添加集成 → 搜索「国内地图」
2. 选择底图数据源（高德/腾讯/HA 自带不需要 Key，天地图需要免费申请）
3. 如选天地图，到 [console.tianditu.gov.cn](https://console.tianditu.gov.cn/api/key) 申请 Key，应用类型选「浏览器端」

### 可用数据源

| 数据源 | 坐标系 | 需要 Key | 最高级别 |
|--------|--------|----------|----------|
| HA 自带地图 | 原生 | 否 | 不限 |
| 高德 · 路网图 | GCJ-02 | 否 | 18 |
| 高德 · 卫星影像 | GCJ-02 | 否 | 18 |
| 腾讯 · 卫星影像 | GCJ-02 | 否 | 20 |
| 天地图 · 矢量 | WGS84 | 是 | 18 |
| 天地图 · 影像 | WGS84 | 是 | 18 |

> **HA 自带地图**：不代理任何上游瓦片、不注入自定义样式，完全使用 Home Assistant 自己的默认底图（HA 2026.10 起已更新内置地图）。适合想随时切回原生体验的场景。

### 地图工具栏

安装后地图界面右下角会出现一个地图图标，点击展开所有数据源列表，选中即可切换，无需进入设置页面。

菜单会根据屏幕剩余空间自动调整：空间不足时上下翻转、超出右边界改右对齐、限高后可滚动，手机竖屏和弹窗内都不会被裁切。

### 选项说明

| 选项 | 默认 | 说明 |
|------|------|------|
| 数据源 | 高德路网图 | 选择底图提供商 |
| 天地图 Key | — | 仅选天地图时显示；切换到不需 Key 的源后原值会保留，切回时不用重填 |
| 坐标纠偏 | 开 | 修正 GCJ-02 偏移，路网与实体对齐 |
| 像素级精确纠偏 | 开 | 每张瓦片拼 4 张源图；关闭后只取 1 张，省 CPU |
| 暗色模式压暗 | 关 | HA 暗色主题下底图太亮时打开 |
| 打印排障日志 | 关 | 上游请求失败时在 HA 日志打印原因 |
| 自动刷新前端 | 开 | 设置变更后自动刷新页面 |

## 技术原理

```
浏览器 (MapLibre/Leaflet)
    │  请求 /static/map/light.json
    ▼
ha-cnmaps.js (注入脚本)
    │  返回集成生成的样式（瓦片地址指向 /ha_cnmaps/tiles/...）
    │  选择「HA 自带地图」时返回 null，样式透传原生
    ▼
HA 服务端瓦片接口
    │  按 WGS84 网格收到 (z,x,y) 请求
    ▼
projection.py → 换算到数据源坐标系 (GCJ-02)
    │  算出需要抓哪 1~4 张上游瓦片
    ▼
tiles.py → 抓取、拼合、编码 → 返回 256x256 PNG/JPEG
```

密钥、Referer、坐标纠偏全部在服务端处理，浏览器只看到一个普通的瓦片接口。
