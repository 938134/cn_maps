# 中国地图 { #cn-maps }

把 Home Assistant 内置地图（地图面板、地图卡片、实体详情小地图）的底图换成高德、腾讯、百度、天地图等国内地图源。

瓦片抓取、坐标纠偏（GCJ-02 / BD-09 → WGS84）全部在 HA 服务端完成，手机 App、网页、老设备看到的地图完全一致，密钥不会下发到浏览器。

## 功能特性

- **8 种底图**：高德路网/卫星、腾讯路网/卫星、百度路网、天地图矢量/影像/地形
- **服务端纠偏**：自动把 GCJ-02 / BD-09 坐标系偏移修正回 WGS84，路网与实体精准对齐
- **像素级精确纠偏**：每张瓦片最多拼 4 张源图，精度到亚像素；关闭后省 CPU
- **百度网格支持**：完整实现 BD09MC 椭球墨卡托投影与百度自有瓦片网格
- **地图工具栏**：地图右下角浮动按钮，一键切换底图数据源，无需进设置页
- **暗色模式压暗**：栅格底图无暗色版本，可在 HA 暗色主题下自动压暗
- **零前端依赖**：不装 Lovelace 卡片、不拦截瓦片请求，只换一个 MapLibre 样式

## 安装

### 通过 HACS 安装（推荐）

1. 打开 HACS → 集成 → 右上角菜单 → 自定义存储库
2. 添加本仓库地址，类别选「集成」
3. 搜索「中国地图」并安装
4. 重启 Home Assistant

### 手动安装

1. 下载 `custom_components/cn_maps/` 整个目录
2. 放到 HA 配置目录的 `custom_components/cn_maps/`
3. 重启 Home Assistant

## 配置

1. 设置 → 设备与服务 → 添加集成 → 搜索「中国地图」
2. 选择底图数据源（高德/腾讯/百度不需要 Key，天地图需要免费申请）
3. 如选天地图，到 [console.tianditu.gov.cn](https://console.tianditu.gov.cn/api/key) 申请 Key，应用类型选「浏览器端」

### 可用数据源

| 数据源 | 坐标系 | 需要 Key | 最高级别 |
|--------|--------|----------|----------|
| 高德 · 路网图 | GCJ-02 | 否 | 18 |
| 高德 · 卫星影像 | GCJ-02 | 否 | 18 |
| 腾讯 · 路网图 | GCJ-02 | 否 | 18 |
| 腾讯 · 卫星影像 | GCJ-02 | 否 | 18 |
| 天地图 · 矢量 | WGS84 | 是 | 18 |
| 天地图 · 影像 | WGS84 | 是 | 18 |
| 天地图 · 地形 | WGS84 | 是 | 14 |
| 百度 · 路网图 | BD-09 | 否 | 18 |

### 地图工具栏

安装后地图界面右下角会出现一个地图图标，点击展开所有数据源列表，选中即可切换，无需进入设置页面。

### 选项说明

| 选项 | 默认 | 说明 |
|------|------|------|
| 数据源 | 高德路网图 | 选择底图提供商 |
| 坐标纠偏 | 开 | 修正 GCJ-02/BD-09 偏移，路网与实体对齐 |
| 像素级精确纠偏 | 开 | 每张瓦片拼 4 张源图；关闭后只取 1 张，省 CPU |
| 暗色模式压暗 | 关 | HA 暗色主题下底图太亮时打开 |
| 打印排障日志 | 关 | 上游请求失败时在 HA 日志打印原因 |
| 自动刷新前端 | 开 | 设置变更后自动刷新页面 |

## 技术原理

```
浏览器 (MapLibre/Leaflet)
    │  请求 /static/map/light.json
    ▼
cn-maps.js (注入脚本)
    │  返回集成生成的样式（瓦片地址指向 /cn_maps/tiles/...）
    ▼
HA 服务端瓦片接口
    │  按 WGS84 网格收到 (z,x,y) 请求
    ▼
projection.py → 换算到数据源坐标系 (GCJ-02/BD-09/BD09MC)
    │  算出需要抓哪 1~4 张上游瓦片
    ▼
tiles.py → 抓取、拼合、编码 → 返回 256x256 PNG/JPEG
```

密钥、Referer、坐标纠偏全部在服务端处理，浏览器只看到一个普通的瓦片接口。
